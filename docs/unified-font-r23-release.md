# R23 统一字体模型验收

候选 `refinement-low` 已通过全部模型发布检查及本地交付验证。
版本为 `r23-unified-font-short-regions-v1-preview`。训练在本机完成；
iOS 和 Android 共用一个字体 ONNX，覆盖 24 类已知字体及未知字体输出。

## 模型改进

在 R22 基础上训练更细的空间特征和未知字体分类参数，补充短文字区分能力。
最终折叠为一个普通 CNN，输出字体类别和估计字号；颜色仍由原图测量。
OCR 仅用于定位文字区域，不识读文字，不参与字体分类。
识别阈值没有修改，也没有加入平台路由、参考图片匹配或模型投票。

## 验收结果

- 原有 46 项及新增 7 项 CAL 检查全部通过。
- Android 错报 PingFang、SF Pro、Helvetica 的 CAL 数量为 26，上限为 27。
- 37,834 个 CAL 图块完成训练模型、折叠模型和 ONNX 数值核对；
  18,672 个区域的字体判定、拒识原因、字号可用状态一致。
- 批量大小 1、7、32、128 的导出一致性检查通过。
- 3,504 个 DEV 区域、5,967 个图块，对 R21 和 R22 的 36 项回归检查全部通过。
- 本地 Docker 的 iOS、Android 整页请求完成，各核对 3 个 API 裁图，
  字体、字号、颜色与下载包独立运行结果一致；6 个用户裁图仅作本地观察，
  没有真实字体标签，因此不计入准确率，也没有上传线上。

| 指标 | R22 | R23 |
| --- | ---: | ---: |
| CAL 短文字正确命名 / 3,055 | 1,607 | 1,669 |
| CAL 短文字未知字体误报 / 752 | 161 | 142 |
| CAL 已命名区域准确率 | 95.33% | 95.80% |
| CAL 已知字体正确识别覆盖率 | 65.47% | 66.94% |
| DEV 已命名区域准确率 | 96.34% | 96.38% |
| DEV 已知字体正确识别覆盖率 | 53.70% | 55.19% |
| DEV 未知字体未误报比例 | 96.99% | 97.27% |

“已命名区域准确率”以模型输出了字体名称的区域为分母；
“正确识别覆盖率”以全部已知字体区域为分母。两者不能混用。
DEV 中正确命名区域的字号相对误差中位数为 3.48%，90 分位为 8.75%。
字号单位是截图像素，不能在未知缩放比例时直接当作 iOS pt 或 Android sp。
