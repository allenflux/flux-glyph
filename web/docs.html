模型包包含字体 ONNX、元数据、预处理与推理代码、predict.py、README 和 requirements.txt。输入一张包含单行或单个文字区域的裁图，返回字体候选、估计字号和可见文字颜色；无需提供文字内容。

The ZIP includes the font ONNX model, metadata, preprocessing and inference code, predict.py, README, and requirements.txt. Supply a crop containing one text line or region to receive font candidates, estimated size, and visible text color. No transcription is required.

字体来源见首页“本地使用方式”和模型元数据：Alipay Number 是应用自带数字字体，不是 iOS 系统字体。模型若将苹方显示为 PingFang，表示识别到了字体族；简体、繁体字形可能由多个地区版本共同提供，不能由此确定 SC、TC 或 HK。

Font origins appear under Local usage on the home page and in model metadata. Alipay Number is an app-bundled numeric font, not an iOS system font. A PingFang result identifies the family: simplified and traditional glyphs can be shared across regional variants, so it does not identify SC, TC, or HK.

首页可选择 iOS 或 Android 实验候选，两种范围使用独立模型，默认 iOS R20。安卓首版为 android-open-fonts-v1-preview，覆盖 Noto 黑体／宋体、霞鹜文楷、文泉驿微米黑、三款站酷字体、马善政和 Roboto，共九类，尚未通过稳定版验收。这些字体由采集应用加载，不表示它们都是手机系统默认字体。选择安卓范围不用于证明截图系统。

The home page offers independent iOS and Android preview models, with iOS R20 selected by default. The Android version is android-open-fonts-v1-preview. It covers nine families: Noto Sans/Serif, LXGW WenKai, WenQuanYi Micro Hei, three ZCOOL families, Ma Shan Zheng, and Roboto. It has not passed stable-release validation. The capture app loads these fonts as assets; they are not all phone system defaults. Selecting Android does not establish the screenshot's operating system.

predict.py 会执行与服务一致的预处理。底层模型输入为 float32 的 [N, 1, 64, 256]；建议通过附带脚本使用，保留原图尺寸信息以估算字号。字号单位为输入图片像素，文字颜色为可见 RGB。

predict.py applies the same preprocessing as the service. The underlying model accepts float32 [N, 1, 64, 256] input. Use the included script to preserve source dimensions for size estimation. Font size uses input-image pixels and text color is visible RGB.

GET /api/models/font 返回 available、version、families、input_shape、download_url、bytes、ocr_required 和 usage；ocr_required 为 false。可用字体和版本以该接口及包内元数据为准。字体分数不是实际准确率。

GET /api/models/font returns available, version, families, input_shape, download_url, bytes, ocr_required, and usage. ocr_required is false. The endpoint and packaged metadata define the available families and version. Font scores are not measured accuracy.

安卓的模型信息、下载和图片上传地址均添加 ?mode=android，例如 POST /api/jobs?mode=android；不指定时使用 iOS。任务提交时固定模式，结果包含 font_mode。安卓模型不可用时返回 503，不会改用 iOS 模型。两种模式共用同一队列。

Add ?mode=android to model information, download, and image upload URLs, such as POST /api/jobs?mode=android. Omitted mode uses iOS. Each submitted job keeps its selected mode and returns font_mode. Android inference returns 503 when its model is unavailable, without falling back to iOS. Both modes share one queue.

安卓模型信息接口和 ZIP 内元数据声明 release_tier 为 experimental，test_passed 与 stable_validation_passed 均为 false；validation 提供实际评测与适用范围。预测 API 与 CLI JSON 则返回 model_release_tier 为 experimental、stable_validation_passed 为 false。实验版可主动选择试用，这些字段不会把失败测试改成通过。

The Android model information endpoint and ZIP metadata declare release_tier as experimental, with test_passed and stable_validation_passed both false; validation describes the measured results and scope. Prediction API and CLI JSON instead return model_release_tier as experimental and stable_validation_passed as false. The model is available for voluntary preview use; availability does not turn a failed test into a pass.

启用访问令牌时，网页下载复用解锁后的 Cookie。命令行下载需使用 Authorization: Bearer 请求头；令牌无需放入下载地址。

When access tokens are enabled, browser downloads use the cookie set by unlocking the site. Command-line downloads use the Authorization: Bearer header; tokens do not belong in download URLs.

android-open-fonts-v1-preview 尚未通过稳定版验收。它使用第一轮冻结权重，供主动下载和试用；输出是候选字体，模型分数不是正确概率，范围外字体仍可能被误命名。

android-open-fonts-v1-preview has not passed stable-release validation.It uses the frozen first-round weights for voluntary download and testing. Outputs are font candidates, model scores are not probabilities of correctness, and unsupported fonts may still receive an incorrect name.

The preview completed 6,000 local MPS training steps using 33 font instances; the full capture corpus contains 35. Train, calibration, and test contain 600, 100, and 100 pages. The emulator app explicitly loads font assets, so these are neither real-device captures nor evidence of manufacturer system defaults. 提交单张图片

Submit an image

curl -F "file=@./alipay.png" http://allenflux.tech:9000

成功返回 200 与完整结果；120 秒仍未完成时返回 202 与任务 ID，用 GET /api/jobs/{id} 继续查询。

Returns 200 with the result, or 202 with a job ID if processing takes longer than 120 seconds. Continue with GET /api/jobs/{id}.

支持 PNG、JPEG、WebP，默认不超过 8 MB、1200 万像素。无需手写 Content-Type 或 X-Filename，curl 会自动带上表单格式和文件名。

Supports PNG, JPEG, and WebP, up to 8 MB and 12 megapixels by default. No Content-Type or X-Filename headers are required: curl supplies the form format and filename.

直接上传文件

Direct file upload

curl -T ./alipay.png http://allenflux.tech:9000/upload/alipay.png

curl -F "file=@./alipay.png" http://allenflux.tech:9000/upload

根地址和 /upload 默认在完成后返回识别 JSON；加 ?wait=false 可先返回任务 ID。接口检查实际图片内容。

The root URL and /upload return recognition JSON when complete. Add ?wait=false to receive a job ID first. The service validates the actual image contents.

异步任务

Asynchronous jobs

curl -F "file=@./alipay.png" http://allenflux.tech:9000/api/jobs

curl http://allenflux.tech:9000/api/jobs/TASK_ID
curl -o result.json http://allenflux.tech:9000/api/jobs/TASK_ID/json
curl -o annotated.png http://allenflux.tech:9000/api/jobs/TASK_ID/image

任务状态为 queued、running、complete 或 error。只有 complete 时返回 result。结果过期或不存在返回 404。

Job states are queued, running, complete, and error. The result is available only when complete. Missing or expired jobs return 404.

网页按 R001 等区域编号展示原图裁图、字体候选、字号和颜色；点击区域缩略图可查看对应原图框与详情。页面保留格式化 JSON、复制 JSON 和标注 PNG 下载。

The website identifies regions by IDs such as R001 and displays their source crops, font candidates, sizes, and colors. Select a thumbnail to inspect its source box and details. Formatted JSON, JSON copy, and annotated PNG downloads are available.

有神经网络评分时，列表和详情直接显示最接近的字体及原始评分（例如 0.6559），包括待确认区域；未确认原因仍可查看。没有有效输出时显示“未生成评分”。模型评分不是实际准确率，历史参考距离不换算为评分。API 的 font.family 在待确认时仍为 null，候选预测可从 font.candidates 读取；页面显示和语言切换不改变原始 JSON。

When neural scores are available, the list and details show the closest font and its raw score, such as 0.6559, including regions that still need review. The reason remains visible. Missing output shows No score available. Model scores are not measured accuracy; legacy reference distances are not converted to scores. The API keeps font.family null for unconfirmed regions, with predictions in font.candidates. Display and language changes do not modify the original JSON.

队列与进度

Queue and progress

默认同时处理 1 个任务，最多 8 个等待。queue_position 为等待队列中的位置，从 1 开始；运行时为 0，结束时为 null。queue_ahead 是前方未完成的任务数；queue_total 是正在等待的任务数。

By default, one job runs at a time and up to eight jobs may wait. queue_position starts at 1 for waiting jobs, is 0 while running, and null after completion. queue_ahead counts unfinished jobs ahead; queue_total counts all waiting jobs.

progress.stage_code 表示当前阶段；percent 在准备、检测时可为 null。开始逐区域处理后，按实际完成的处理步骤更新，current / total 是本阶段的区域计数。这不是剩余时间估算，只有结果保存成功后才会到 100。

progress.stage_code identifies the current stage. percent may be null during preparation and detection. During region processing it reflects completed operations; current / total counts regions within that stage. It is not a time estimate and reaches 100 only after the result is saved.

队列或上传接收槽已满时返回 429，并带 Retry-After: 2。已拿到任务 ID 后，仅重试 GET 查询；不要因查询断线重新提交同一张图片。

A full queue or occupied upload slots return 429 with Retry-After: 2. Once a job ID is received, retry its GET request instead of submitting the image again after a connection failure.

结果保留

Result retention

默认最多保留 7 天，并设 100 个已结束任务的数量上限；超过上限时会提前删除最旧的结果。服务自动清理整个任务目录，包括原图、裁图、标注 PNG 和 JSON；排队、处理中的任务保留。清理后相关接口返回 404。管理员可通过 FLUX_RETENTION_HOURS 和 FLUX_MAX_SAVED_JOBS 调整策略。

Results are retained for up to 7 days by default, with a limit of 100 finished jobs. The oldest results may be removed earlier when the limit is reached. Automatic cleanup removes the entire job directory, including source images, crops, annotated PNGs, and JSON; queued and running jobs are preserved. Removed results return 404. Administrators can configure FLUX_RETENTION_HOURS and FLUX_MAX_SAVED_JOBS.

结果字段

Result fields

regions 包含每个文字区域的 id、quad、detector_bbox、source_bbox、font、text_style 和 crop_url。坐标对应 EXIF 方向校正后的原图。source_bbox 比检测框多保留少量边缘。新模型直接处理区域图像，不进行文字识读；ocr_performed 为 false，text 为 null 或空字符串，glyphs 不提供逐字证据。

Each region includes id, quad, detector_bbox, source_bbox, font, text_style, and crop_url. Coordinates refer to the source image after EXIF orientation correction; source_bbox retains a small margin. The new model processes region images without transcribing text: ocr_performed is false, text is null or empty, and glyphs supplies no character evidence.

font.status：candidate 表示通过当前确认门槛的字体候选；uncertain 表示证据不足或多个候选接近；out_of_scope 表示模型尚未覆盖。font.scope 为 Detected text region，表示结论针对整个检测区域。混合字体、模糊或字体外观接近时可能无法给出单一字体结论。

font.status: candidate passes the current confirmation gates; uncertain indicates insufficient evidence or similar candidates; out_of_scope indicates missing model coverage. font.scope is Detected text region, describing the entire detected region. Mixed fonts, blur, or similar typefaces may prevent a single-family verdict.

新模型的 font_method 和 font.method 为 region_neural_network。区域图像直接输入训练后的字体 CNN，不需要文字内容或人工选择文字类型。candidates 包含 family 和 score，并返回 margin。分数描述已知类别间的相对评分，不是实际准确率，也不保证拒绝所有未知字体。历史结果仍保留原始 JSON。

The new model returns region_neural_network in font_method and font.method. Region images enter a trained font CNN directly, without transcribed text or a manually selected script. candidates contains family and score, with margin for separation. Scores compare known classes; they are not measured accuracy and do not guarantee rejection of all unknown fonts. Historical results retain their original JSON.

每个区域的 text_style 返回 font_size_px_estimate（截图像素中的估计字号）、font_size_px_interval（估计范围）和 text_color_hex（#RRGGBB 可见文字颜色）。字号由区域模型结合原图尺度估算；它不是文字框高度，也不是原始 iOS pt。缩放、压缩、低对比度或混色可能影响估计；证据不足时对应字段为 null，color 和 size 给出状态及原因。

Each region includes text_style with font_size_px_estimate (estimated font size in screenshot pixels), font_size_px_interval (estimated range), and text_color_hex (#RRGGBB visible text color). Size uses the region model and source image scale; it is neither the text box height nor original iOS points. Resizing, compression, low contrast, and mixed colors can affect estimates. Insufficient evidence yields null; color and size include status and reason.

annotated_image_url 下载原尺寸标注 PNG；download_json_url 下载 JSON。URL 均为相对路径，前面加本服务地址即可。界面语言切换不会改写 API 的原始 JSON。

annotated_image_url downloads an annotated PNG at source dimensions; download_json_url downloads JSON. URLs are relative to the service address. Changing the interface language does not alter the original API JSON.
