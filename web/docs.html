单独下载并使用字体模型

Download and run the font model

统一字体模型使用一个联合训练的 CNN、一个字体 ONNX，同时处理 iOS 和 Android 文字区域截图。无需选择平台。完整截图先检测文字位置，字体网络直接分析区域图像，不进行 OCR 识字。

The unified font model uses one jointly trained CNN and one font ONNX for text-region crops from both iOS and Android. No platform selection is needed. Full screenshots first undergo text-region detection; the font network reads region pixels without OCR transcription.

Frozen development regression covers 91 pages, 1,092 native regions, and 3,504 correlated views: precision 96.49% (1,621 / 1,680), correct-name coverage 51.66% (1,621 / 3,138), and unknown withholding 98.36% (360 / 366). The ZIP contains one font/size ONNX, metadata.json, preprocessing and inference code, color measurement, predict.py, README, requirements.txt, and SHA256 checksums. Supply one text line or region crop. No transcription, platform parameter, or additional rejection/verifier model is required.

predict.py 使用与服务相同的预处理，保留图像比例与原始尺度。底层输入为 float32 [N,1,64,256]，输出字体 logits [N,C] 和 log_em_ratio [N]。本轮训练 24 个具名字体及一个未知类别；C 和类别顺序以元数据为准。不要把完整截图直接拉伸为单个图块。

predict.py applies the same preprocessing as the service while retaining image proportions and source scale. Inputs are float32 [N,1,64,256]; outputs are font logits [N,C] and log_em_ratio [N]. This training run has 24 named families and one unknown class; metadata defines C and class order. Do not stretch an entire screenshot into a single tile.

字号是输入截图中的像素 em 大小，不是 iOS pt、Android sp 或文字框高度。颜色为可见 RGB（#RRGGBB）。缩放会改变像素字号，混色和压缩会影响颜色；证据不足时相应结果为 null。

Size is the estimated em size in input-image pixels, not iOS points, Android sp, or bounding-box height. Color is visible RGB (#RRGGBB). Resizing changes pixel sizes, and blended colors or compression can affect color estimates. Insufficient evidence produces null values.

具名范围包括 PingFang、SF Pro、Helvetica、Roboto、Noto 黑体／宋体组、霞鹜文楷、文泉驿微米黑、三款站酷字体、马善政、Fandol 黑／楷／宋、Long Cang、Zhi Mang Xing、Kaiti SC、Songti SC、HanziPen SC，以及 HarmonyOS Sans SC、MiSans、OPPO Sans、Alipay Number。可用名称以当前模型信息为准。

Named coverage includes PingFang, SF Pro, Helvetica, Roboto, Noto Sans/Serif groups, LXGW WenKai, WenQuanYi Micro Hei, three ZCOOL families, Ma Shan Zheng, Fandol Hei/Kai/Song, Long Cang, Zhi Mang Xing, Kaiti SC, Songti SC, HanziPen SC, HarmonyOS Sans SC, MiSans, OPPO Sans, and Alipay Number. The active model information defines the names currently available.

PingFang 表示 SC／TC／HK 字体族，不确定地区版本。FandolKai 与 Kaiti SC、FandolSong 与 Songti SC 是不同类别。Alipay Number 是应用数字字体；Kaiti SC、Songti SC、HanziPen SC 在本批原生采集中也是应用加载资产。字体名不能证明截图系统。

PingFang groups SC, TC, and HK without identifying a regional version. FandolKai and Kaiti SC, and FandolSong and Songti SC, remain separate classes. Alipay Number is an app font; Kaiti SC, Songti SC, and HanziPen SC were also loaded as assets in this capture corpus. A font name does not establish the screenshot's operating system.

训练来源为受控 iOS／Android 模拟器原生截图，不是实体手机采集。TRAIN 有 70,128 个相关视图／19,803 个原生区域，CAL 有 18,672／5,424，开发保留集有 3,504／1,092。开发保留图片可能被初始化网络见过，不称为盲测；原先封存的第二批 Android TEST 本轮仍未用于训练或选择。

Data comes from controlled native iOS/Android emulator screenshots, not physical-device captures. TRAIN has 70,128 correlated views from 19,803 native regions; CAL has 18,672 from 5,424; the development holdout has 3,504 from 1,092. The initializer may have seen development-holdout images, so this is not a blind test. The second Android TEST remains excluded from training and model selection.

候选评分不是实际正确概率，未知类也不保证拒绝所有未覆盖字体。校准时偏好命名精度至少 95% 的方案，稳定验收另有更严格条件；不能把偏好、模型可下载或任务完成当成验收通过。

Candidate scores are not probabilities of correctness, and the unknown class does not guarantee rejection of every unsupported font. Calibration prefers configurations with at least 95% naming precision; stable validation has separate, stricter criteria. A preference, downloadable model, or completed job does not mean validation passed.

GET /api/models/font 提供 available、version、families、download_url、bytes、sha256 和 usage。完整截图统一提交 POST /api/jobs。启用令牌时，网页下载复用解锁 Cookie；命令行使用 Authorization: Bearer 请求头，不把令牌放进 URL。

GET /api/models/font provides available, version, families, download_url, bytes, sha256, and usage. Submit full screenshots to POST /api/jobs. With access tokens enabled, browser downloads reuse the unlocked cookie; command-line requests use an Authorization: Bearer header, not a token in the URL.

返回统一模型下载与说明Back to unified model downloads and usage

提交单张图片

Submit an image

curl -F "file=@./alipay.png" http://allenflux.tech:9000

成功返回 200 与完整结果；120 秒仍未完成时返回 202 与任务 ID，用 GET /api/jobs/{id} 继续查询。

Returns 200 with the result, or 202 with a job ID if processing takes longer than 120 seconds. Continue with GET /api/jobs/{id}.

支持 PNG、JPEG、WebP，默认不超过 8 MB、1200 万像素。无需手写 Content-Type 或 X-Filename，curl 会自动带上表单格式和文件名。

Supports PNG, JPEG, and WebP, up to 8 MB and 12 megapixels by default. No Content-Type or X-Filename headers are required: curl supplies the form format and filename.

直接上传文件

Direct file upload

curl -T ./alipay.png http://allenflux.tech:9000/upload/alipay.png

curl -F "file=@./alipay.png" http://allenflux.tech:9000/upload

根地址和 /upload 默认在完成后返回识别 JSON；加 ?wait=false 可先返回任务 ID。接口检查实际图片内容。

The root URL and /upload return recognition JSON when complete. Add ?wait=false to receive a job ID first. The service validates the actual image contents.

异步任务

Asynchronous jobs

curl -F "file=@./alipay.png" http://allenflux.tech:9000/api/jobs

curl http://allenflux.tech:9000/api/jobs/TASK_ID
curl -o result.json http://allenflux.tech:9000/api/jobs/TASK_ID/json
curl -o annotated.png http://allenflux.tech:9000/api/jobs/TASK_ID/image

任务状态为 queued、running、complete 或 error。只有 complete 时返回 result。结果过期或不存在返回 404。

Job states are queued, running, complete, and error. The result is available only when complete. Missing or expired jobs return 404.

网页按 R001 等区域编号展示原图裁图、字体候选、字号和颜色；点击区域缩略图可查看对应原图框与详情。页面保留格式化 JSON、复制 JSON 和标注 PNG 下载。

The website identifies regions by IDs such as R001 and displays their source crops, font candidates, sizes, and colors. Select a thumbnail to inspect its source box and details. Formatted JSON, JSON copy, and annotated PNG downloads are available.

有神经网络评分时，列表和详情直接显示最接近的字体及原始评分（例如 0.6559），包括待确认区域；未确认原因仍可查看。没有有效输出时显示“未生成评分”。模型评分不是实际准确率，历史参考距离不换算为评分。API 的 font.family 在待确认时仍为 null，候选预测可从 font.candidates 读取；页面显示和语言切换不改变原始 JSON。

When neural scores are available, the list and details show the closest font and its raw score, such as 0.6559, including regions that still need review. The reason remains visible. Missing output shows No score available. Model scores are not measured accuracy; legacy reference distances are not converted to scores. The API keeps font.family null for unconfirmed regions, with predictions in font.candidates. Display and language changes do not modify the original JSON.

队列与进度

Queue and progress

默认同时处理 1 个任务，最多 8 个等待。queue_position 为等待队列中的位置，从 1 开始；运行时为 0，结束时为 null。queue_ahead 是前方未完成的任务数；queue_total 是正在等待的任务数。

By default, one job runs at a time and up to eight jobs may wait. queue_position starts at 1 for waiting jobs, is 0 while running, and null after completion. queue_ahead counts unfinished jobs ahead; queue_total counts all waiting jobs.

progress.stage_code 表示当前阶段；percent 在准备、检测时可为 null。开始逐区域处理后，按实际完成的处理步骤更新，current / total 是本阶段的区域计数。这不是剩余时间估算，只有结果保存成功后才会到 100。

progress.stage_code identifies the current stage. percent may be null during preparation and detection. During region processing it reflects completed operations; current / total counts regions within that stage. It is not a time estimate and reaches 100 only after the result is saved.

队列或上传接收槽已满时返回 429，并带 Retry-After: 2。已拿到任务 ID 后，仅重试 GET 查询；不要因查询断线重新提交同一张图片。

A full queue or occupied upload slots return 429 with Retry-After: 2. Once a job ID is received, retry its GET request instead of submitting the image again after a connection failure.

结果保留

Result retention

默认最多保留 7 天，并设 100 个已结束任务的数量上限；超过上限时会提前删除最旧的结果。服务自动清理整个任务目录，包括原图、裁图、标注 PNG 和 JSON；排队、处理中的任务保留。清理后相关接口返回 404。管理员可通过 FLUX_RETENTION_HOURS 和 FLUX_MAX_SAVED_JOBS 调整策略。

Results are retained for up to 7 days by default, with a limit of 100 finished jobs. The oldest results may be removed earlier when the limit is reached. Automatic cleanup removes the entire job directory, including source images, crops, annotated PNGs, and JSON; queued and running jobs are preserved. Removed results return 404. Administrators can configure FLUX_RETENTION_HOURS and FLUX_MAX_SAVED_JOBS.

结果字段

Result fields

regions 包含每个文字区域的 id、quad、detector_bbox、source_bbox、font、text_style 和 crop_url。坐标对应 EXIF 方向校正后的原图。source_bbox 比检测框多保留少量边缘。新模型直接处理区域图像，不进行文字识读；ocr_performed 为 false，text 为 null 或空字符串，glyphs 不提供逐字证据。

Each region includes id, quad, detector_bbox, source_bbox, font, text_style, and crop_url. Coordinates refer to the source image after EXIF orientation correction; source_bbox retains a small margin. The new model processes region images without transcribing text: ocr_performed is false, text is null or empty, and glyphs supplies no character evidence.

font.status：candidate 表示通过当前确认门槛的字体候选；uncertain 表示证据不足或多个候选接近；out_of_scope 表示模型尚未覆盖。font.scope 为 Detected text region，表示结论针对整个检测区域。混合字体、模糊或字体外观接近时可能无法给出单一字体结论。

font.status: candidate passes the current confirmation gates; uncertain indicates insufficient evidence or similar candidates; out_of_scope indicates missing model coverage. font.scope is Detected text region, describing the entire detected region. Mixed fonts, blur, or similar typefaces may prevent a single-family verdict.

新模型的 font_method 和 font.method 为 region_neural_network。区域图像直接输入训练后的字体 CNN，不需要文字内容或人工选择文字类型。candidates 包含 family 和 score，并返回 margin。分数来自包含未知类的完整类别评分，不是实际准确率，也不保证拒绝所有未知字体。历史结果仍保留原始 JSON。

The new model returns region_neural_network in font_method and font.method. Region images enter a trained font CNN directly, without transcribed text or a manually selected script. candidates contains family and score, with margin for separation. Scores use all classes, including unknown; they are not measured accuracy and do not guarantee rejection of all unknown fonts. Historical results retain their original JSON.

每个区域的 text_style 返回 font_size_px_estimate（截图像素中的估计字号）、font_size_px_interval（当前区域模型为 null，不表示置信区间）和 text_color_hex（#RRGGBB 可见文字颜色）。字号由区域模型结合原图尺度估算；它不是文字框高度，也不是原始 iOS pt。缩放、压缩、低对比度或混色可能影响估计；证据不足时对应字段为 null，color 和 size 给出状态及原因。

Each region includes text_style with font_size_px_estimate (estimated font size in screenshot pixels), font_size_px_interval (null for the current region model, not a confidence interval), and text_color_hex (#RRGGBB visible text color). Size uses the region model and source image scale; it is neither the text box height nor original iOS points. Resizing, compression, low contrast, and mixed colors can affect estimates. Insufficient evidence yields null; color and size include status and reason.

annotated_image_url 下载原尺寸标注 PNG；download_json_url 下载 JSON。URL 均为相对路径，前面加本服务地址即可。界面语言切换不会改写 API 的原始 JSON。

annotated_image_url downloads an annotated PNG at source dimensions; download_json_url downloads JSON. URLs are relative to the service address. Changing the interface language does not alter the original API JSON.
